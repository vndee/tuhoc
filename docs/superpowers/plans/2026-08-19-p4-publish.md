# P4 — Publish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mở nền tảng cho người dùng khác: OAuth, catalog khóa học public, kiểm soát chi phí AI, vận hành an toàn trên free tier.

**Architecture:** Không đổi kiến trúc (spec §7) — thêm lớp: OAuth cạnh password auth, cờ `visibility` đã có sẵn trong schema từ P1, quota AI đã có khung từ P3. Vào cửa bằng invite code giai đoạn đầu (free tier, chống abuse) — mở đăng ký tự do là một cờ env về sau.

**Tech Stack:** thêm `github.com/markbates/goth` (GitHub + Google OAuth). Không thêm gì phía frontend.

**Spec:** `docs/superpowers/specs/2026-08-19-tuhoc-platform-design.md` (§7 Publish, §4 bảo mật)

## Global Constraints

- Link tài khoản OAuth ↔ password theo email (citext, đã UNIQUE); không tạo user trùng email.
- Dữ liệu người học đã cô lập theo `user_id` từ P1 — P4 KHÔNG được thêm endpoint nào trả dữ liệu người khác.
- Invite required khi `OPEN_SIGNUP=0` (mặc định); áp cho cả register lẫn OAuth lần đầu.
- Rate limit toàn cục per-IP và per-user cho API mutation; AI quota per-user theo `ai_usage` (P3).
- Không thu thập analytics bên thứ ba; chỉ `events` nội bộ.

### Task 1: Migration 0003 — identities + invites + visibility flow

**Files:** Create: `migrations/0003_publish.up.sql`, `.down.sql`, `internal/invite/repo.go`, test.

**Interfaces:** Produces:

```sql
CREATE TABLE identities (
  provider text NOT NULL, provider_id text NOT NULL,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (provider, provider_id));
CREATE TABLE invites (
  code text PRIMARY KEY,                        -- 12 ký tự base32, sinh bằng lệnh admin
  created_by uuid, used_by uuid REFERENCES users(id),
  created_at timestamptz NOT NULL DEFAULT now(), used_at timestamptz);
ALTER TABLE users ALTER COLUMN pw_hash DROP NOT NULL;   -- user OAuth-only không có mật khẩu
UPDATE courses SET visibility='public' WHERE id='***REMOVED***';
```

### Task 2: OAuth GitHub + Google

**Files:** Create: `internal/oauth/handler.go`, test · Modify: server.go, `internal/auth/usecase.go` (hàm `FindOrCreateByEmail`).

**Interfaces:** Produces:
- `GET /auth/oauth/:provider` → redirect goth; `GET /auth/oauth/:provider/callback` → flow:
  1. Lấy email đã verify từ provider (không có email verified → 400 thông điệp rõ).
  2. `identities` có (provider, provider_id) → login (tạo session P1, cookie như cũ).
  3. Chưa có identity, email khớp user cũ → link identity + login.
  4. User hoàn toàn mới: nếu `OPEN_SIGNUP=0` → yêu cầu invite: redirect `/login?need_invite=1&ticket=<jwt 10 phút chứa provider+id+email>`; frontend gửi `POST /auth/oauth/complete {ticket, inviteCode}` → Claim invite → tạo user + identity + session.
- Env: `OAUTH_GITHUB_KEY/SECRET`, `OAUTH_GOOGLE_KEY/SECRET`, `OAUTH_CALLBACK_BASE`, `SIGNUP_TICKET_SECRET`.

- [ ] **Step 1:** Test fail (fake provider qua goth test helper hoặc stub interface quanh goth): 4 nhánh trên + invite sai → 403, invite đã dùng → 403, và login bằng mật khẩu vào user OAuth-only (`pw_hash IS NULL`) → 401 sạch, không panic (guard trong `internal/auth/usecase.go` trước khi gọi argon2id). **Step 2:** RED → implement → GREEN. **Step 3:** Sửa `POST /auth/register`: khi `OPEN_SIGNUP=0` yêu cầu field `inviteCode`, Claim trong cùng transaction tạo user (test thêm 2 case). **Step 4:** Commit `feat(api): oauth github/google + invite gate`

### Task 3: Hardening

**Files:** Create: `internal/server/hardening.go`, test · Modify: server.go.

**Interfaces:** Produces middleware chuỗi:
- Security headers: `X-Content-Type-Options: nosniff`, `Referrer-Policy: same-origin`, `X-Frame-Options: DENY`.
- Limiter per-IP: 300 req/phút toàn API; per-user: 60 mutation/phút cho `POST /sync|/events/batch`; `/ai/chat` 10 req/phút/user (chồng lên token quota P3).
- Body limit 1MB (annotations batch lớn nhất hợp lệ vẫn dưới xa).
- **`GET /courses` — TẠO MỚI endpoint này** (P1 không task nào xây; Dashboard P1 dùng danh sách hardcode tạm). Trả danh sách course, chỉ `visibility='public'` cho user thường (test: course private không lộ; test: Dashboard đọc được thật thay vì hardcode).

- [ ] **Step 1:** Test fail: vượt limiter → 429; header có mặt; body 2MB → 413. **Step 2:** RED → implement → GREEN. **Step 3:** Commit `feat(api): hardening`
