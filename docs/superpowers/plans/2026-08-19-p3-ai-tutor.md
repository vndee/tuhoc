# P3 — AI Tutor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Panel chat "Hỏi AI" trong reader: hỏi tự do theo ngữ cảnh chương, hoặc bôi chọn văn bản → "Đào sâu"; streaming; hội thoại lưu theo chương, đồng bộ giữa thiết bị.

**Architecture:** Backend proxy Claude API (key server-side, không bao giờ xuống client), SSE streaming qua Fiber. Context lấy từ `getContext()` (đã có từ P1 Task 11). AI threads server-authoritative (không offline, không LWW — chat cần mạng sẵn rồi).

**Tech Stack:** thêm `github.com/anthropics/anthropic-sdk-go` (backend). Model mặc định `claude-sonnet-5`, cấu hình qua env `AI_MODEL`; `ANTHROPIC_API_KEY` env. Frontend không thêm dependency (SSE bằng fetch + ReadableStream).

**Spec:** `docs/superpowers/specs/2026-08-19-tuhoc-platform-design.md` (§6)

## Global Constraints

- API key chỉ ở server (env); log không chứa nội dung tin nhắn (spec §4 tinh thần "không log note").
- Quota P3 (single-user nhưng đặt sẵn khung): `AI_DAILY_TOKEN_BUDGET` env, mặc định 200000 token/ngày/user; vượt → 429 với thông điệp rõ.
- System prompt LUÔN chứa: tên course, chương, headingTrail, và (nếu có) đoạn bôi chọn — model phải trả lời trong ngữ cảnh giáo trình, tiếng Việt.
- Mọi endpoint AI sau `auth.Require`.

### Task 1: Migration 0002 + repo

**Files:** Create: `migrations/0002_ai.up.sql`, `.down.sql`, `internal/ai/repo.go`, test.

**Interfaces:** Produces:

```sql
CREATE TABLE ai_threads (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  course_id text NOT NULL, chapter_id text NOT NULL,
  title text NOT NULL DEFAULT '', created_at timestamptz NOT NULL DEFAULT now());
CREATE TABLE ai_messages (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  thread_id uuid NOT NULL REFERENCES ai_threads(id) ON DELETE CASCADE,
  role text NOT NULL CHECK (role IN ('user','assistant')),
  content text NOT NULL, created_at timestamptz NOT NULL DEFAULT now());
CREATE TABLE ai_usage (
  user_id uuid NOT NULL, day date NOT NULL, tokens bigint NOT NULL DEFAULT 0,
  PRIMARY KEY (user_id, day));
CREATE INDEX idx_ai_threads_user ON ai_threads (user_id, course_id, chapter_id, created_at);
```

Repo: `CreateThread`, `ListThreads(user, course, chapter)`, `AppendMessage`, `ListMessages(thread)` (kiểm user sở hữu), `AddUsage(user, day, tokens) → total`, `GetUsage`.

### Task 3: POST /ai/chat SSE + quota

**Files:** Create: `internal/ai/{handler.go,usecase.go}` · Modify: server.go (mount, inject Upstream — fake trong test, anthropic trong main).

**Interfaces:** Produces:
- `GET /ai/threads?courseId&chapterId` → `[{id,title,createdAt}]`; `GET /ai/threads/:id/messages` → `[{role,content,createdAt}]`.
- `POST /ai/chat` body:

```json
{ "threadId": null, "courseId": "…", "chapterId": "…",
  "message": "…", "context": { "headingTrail": ["…"], "selection": "…", "sectionHTML": "…" } }
```

  Response SSE: `event: meta` `{threadId}` (thread mới tạo nếu null, title = 60 ký tự đầu của message) → nhiều `event: delta` `{text}` → `event: done` `{tokens}`. Handler: kiểm quota trước (429 nếu vượt), ghi message user, stream upstream, gom text → ghi message assistant, AddUsage input+output.
- System prompt (template hằng số, đủ nội dung):

```
Bạn là trợ giảng của khóa "{courseTitle}", đang cùng học viên đọc chương {chapterNum} "{chapterTitle}", mục "{headingTrail}". Học viên có nền tảng tốt, muốn hiểu SÂU — ưu tiên trực giác trước, rồi phát biểu chính xác; dùng đúng ký hiệu của giáo trình; toán viết bằng $…$. Nếu học viên bôi chọn đoạn văn, tập trung vào đoạn đó.
{selection != "" → "Đoạn bôi chọn: «{selection}»"}
Nội dung mục đang đọc (để bám ngữ cảnh, không lặp lại nguyên văn): {sectionText — sectionHTML đã strip thẻ, cắt 4000 ký tự}
```

- [ ] **Step 1: Test fail** (integration, fake upstream): chat mới → meta có threadId + deltas đúng thứ tự + done; DB có 2 messages; quota: set budget=1 → 429; thread user khác → 404. **Step 2:** RED → implement (Fiber SSE: `c.Context().SetBodyStreamWriter`, flush từng event). **Step 3:** GREEN. Commit `feat(api): ai chat sse + quota`
