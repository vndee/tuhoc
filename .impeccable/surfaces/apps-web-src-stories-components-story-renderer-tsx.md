# StoryRenderer — public special-edition narrative grammar

THESIS: One reusable narrative grammar, with art direction owned by each issue.

STORY: Cover → acts → scenes → coda → sources/making-of.

INTERACTION: Desktop pinned two-plate scrollytelling; mobile inline; one optional deterministic lab per scene.

TRUTH BOUNDARY: Illustration is labeled; claims are sourced; AGI remains contested; no personalization promise.

PERFORMANCE: Metadata/thumbnail at discovery; issue, each lab, and scene assets load lazily; cover ≤250 KB; scene ≤320 KB.

ACCESSIBILITY: Public semantic article, named scene navigation, full keyboard alternatives, reduced motion, local lab/image fallbacks.

New issue = metadata/content/theme/assets/config, never a renderer fork.
